# Preventive Maintenance

Preventive maintenance is essential for keeping facilities in optimal condition and reducing unexpected breakdowns. TransitFM enables systematic planning and execution of routine maintenance tasks.

## Overview

Preventive maintenance involves scheduled, recurring work to maintain equipment and facilities before problems occur. This proactive approach reduces emergency repairs and extends asset lifespan.

## Types of Preventive Maintenance

### Routine Maintenance
Regular tasks performed at fixed intervals:
- HVAC filter changes (monthly)
- Facility inspections (quarterly)
- Cleaning and janitorial services

### Predictive Maintenance
Based on equipment condition monitoring:
- Vibration analysis
- Thermal imaging
- Equipment performance metrics

### Condition-Based Maintenance
Triggered when specific conditions are detected:
- Pressure readings exceed thresholds
- Temperature anomalies detected
- System performance degradation

## Setting Up Preventive Maintenance Plans

### 1. Create a Maintenance Plan
- Navigate to **Preventive Maintenance** → **New Plan**
- Define the plan name and target facility/equipment
- Specify the maintenance frequency (daily, weekly, monthly, quarterly, annually)

### 2. Define Tasks
For each maintenance plan, add specific tasks:
- Task description
- Estimated duration
- Required materials and tools
- Preferred time windows

### 3. Assign Responsibility
- Assign to specific team members or work teams
- Set backup assignments for continuity
- Configure notification settings

### 4. Configure Scheduling
- Set start date and recurrence pattern
- Define exclusion dates (holidays, facility closures)
- Specify time windows for execution

## Maintenance Calendar

The maintenance calendar displays all scheduled preventive maintenance tasks:
- Color-coded by priority and type
- Drag-and-drop rescheduling capability
- Conflict detection for overlapping tasks
- Resource availability checking

## Tracking Completion

When maintenance is performed:
1. Team members log completion via the mobile app or web interface
2. Document work with notes, photos, and meter readings
3. Record any issues or recommendations for follow-up
4. Mark as completed with timestamp

## Maintenance Reports

Generate reports to track:
- Compliance with maintenance schedules
- Equipment condition trends
- Cost analysis by facility or equipment
- Technician productivity metrics

## Best Practices

- Review and adjust maintenance frequency based on historical data
- Keep detailed records of all maintenance performed
- Address any issues identified during preventive maintenance promptly
- Maintain adequate inventory of common replacement parts
- Train staff on proper maintenance procedures
